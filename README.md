# PANTHEON — 神域決戦

神話の神々が戦う、ドット絵の2D対戦格闘ゲーム。Windows ベータ版です。

## ダウンロード

**[Windows ベータ版 0.5.0-beta.3 をダウンロード（約321 MB）](https://github.com/OCToNe1001/pantheon-releases/releases/download/v0.5.0-beta.3/PANTHEON-Windows-v0.5.0-beta.3.zip)**

1. ZIPをダウンロードして、すべて展開します。
2. 展開したフォルダーの **PANTHEON.exe** を開きます。
3. オンライン対戦は「スタート → オンライン対戦」から選びます。

Windows 10 / 11（64ビット）、Microsoft Edge WebView2 Runtime が必要です。初期キャラはミカエル・スサノオ・アヌビス。ゲーム内の神貨で全24キャラを解放できます。

## 遊べるモード

- 1人用：難易度を選べるCPU8連戦
- 2人用：同じPCで対戦
- オンライン：ランダムマッチ／招待コードで友達と対戦
- トレーニング／チュートリアル

ランダムマッチ成立時には、両者のキャラクターとプレイヤー名をVSカットインで表示して自動で対戦が始まります。再戦では同じ部屋でキャラクターを変更し、双方の準備完了で開始します。

## beta.3 の更新

両者のCPU難易度が違うとオンライン対戦の開始約2秒後に同期ズレで中断する不具合を修正しました。対戦する両者とも最新版へ更新してください。1人用の難易度設定やセーブデータは引き継がれます。

全24人の弱・強・下段・対空モーション、方向指定の投げ、キャラ固有の移動・攻撃・状態異常を追加。カムイの接近アーマー、ルーの連続突きと空中強襲、クロノスの時間停止、ツクヨミの月相・見切り、ヘカテの冥火設置などを実装しました。

[詳しい操作・変更数値を見る](https://github.com/OCToNe1001/pantheon-releases/releases/tag/v0.5.0-beta.3)

## beta.2 の追加機能

- プロフィール：名前と全24人から選べるアイコン。名前はゲーム側とサーバー側でチェックします。
- キャラ資料：未解放キャラも、戦い方と実際の攻撃モーションを確認できます。
- 神との交流：神貨で贈り物を購入して好感度を10段階まで育成。全24人に各10章、計240章の個別ストーリーがあります。解放済みの章は何度でも読み返せます。
- 建御雷神などの武器モーションと、各神の命中エフェクトを強化しました。

## アップデート

ゲーム内の **設定 → アップデート → アップデートを確認** から、新しい版を取得できます。ダウンロード後「ゲームを終了して更新」を選ぶと、更新して起動し直します。

アップデート機能のない旧版からは、ゲームを終了し、新しいZIPの中身をフォルダーごと上書きしてください。セーブデータ（神貨・解放キャラ・設定・プロフィール・好感度）は `%LOCALAPPDATA%\PANTHEON` に保存され、引き継がれます。
