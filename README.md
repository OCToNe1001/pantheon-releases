# PANTHEON — 神域決戦

神話の神々が戦う、ドット絵の2D対戦格闘ゲーム。Windows ベータ版です。

## ダウンロード

**[Windows ベータ版 0.5.0-beta.6 をダウンロード（約418 MB）](https://github.com/OCToNe1001/pantheon-releases/releases/download/v0.5.0-beta.6/PANTHEON-Windows-v0.5.0-beta.6.zip)**

1. ZIPをダウンロードして、すべて展開します。
2. 展開したフォルダーの **PANTHEON.exe** を開きます。
3. オンライン対戦は「スタート → オンライン対戦」から選びます。

Windows 10 / 11（64ビット）、Microsoft Edge WebView2 Runtime が必要です。初期キャラはミカエル・スサノオ・アヌビス。ゲーム内の神貨で全24キャラを解放できます。

## 遊べるモード

- 1人用：難易度を選べるCPU8連戦
- 2人用：同じPCで対戦
- オンライン：ランダムマッチ／招待コードで友達と対戦
- トレーニング／チュートリアル

ランダムマッチ成立時には、両者のキャラクターとプレイヤー名をVSカットインで表示して自動で対戦が始まります。再戦では同じ部屋でキャラクターを変更し、双方の準備完了で開始します。

## beta.6 の更新

全24人・240章の交流ストーリーを加筆し、専用ノベル画面を追加。フレンド対戦のステージ抽選・準備完了を修正し、ミカエル・オーディン・フォルトゥナとジャストガードを調整しました。

- 全240章を8場面構成へ拡充。立ち絵・会話ログ・Enter／Space送りを備えたノベル画面。
- お知らせをカテゴリ別の見出し・要約・詳細へ整理。
- 招待部屋は毎試合ランダムステージ。準備完了は明示的なキャンセルまで保持。
- ミカエルはUの追尾羽3枚＋背後ダッシュ。オーディンはカラス1羽0.5本。フォルトゥナはUで8秒のランダム強化。
- ジャストガードは全高さから成立。オンライン試合中の一時停止を無効化。
- 全24人のLv10衣装解放と戦闘ドット切り替えを検証。

[詳しい変更内容](https://github.com/OCToNe1001/pantheon-releases/releases/tag/v0.5.0-beta.6)

## beta.2 の追加機能

- プロフィール：名前と全24人から選べるアイコン。名前はゲーム側とサーバー側でチェックします。
- キャラ資料：未解放キャラも、戦い方と実際の攻撃モーションを確認できます。
- 神との交流：神貨で贈り物を購入して好感度を10段階まで育成。全24人に各10章、計240章の個別ストーリーがあります。解放済みの章は何度でも読み返せます。
- 建御雷神などの武器モーションと、各神の命中エフェクトを強化しました。

## アップデート

**beta.5以降は起動時に更新を確認し、新版を自動ダウンロード・適用します。** 通信できないときは現在の版で起動できます。beta.4以前からの初回更新は **設定 → アップデート → アップデートを確認** で取得し、「ゲームを終了して更新」を選んでください。

アップデート機能のない旧版からは、ゲームを終了し、新しいZIPの中身をフォルダーごと上書きしてください。セーブデータ（神貨・解放キャラ・設定・プロフィール・好感度）は `%LOCALAPPDATA%\PANTHEON` に保存され、引き継がれます。
