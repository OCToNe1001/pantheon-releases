# PANTHEON — 神域決戦

神話の神々が戦う、ドット絵の2D対戦格闘ゲーム。Windows ベータ版です。

## ダウンロード

**[Windows ベータ版 0.5.0-beta.10 をダウンロード（約418 MB）](https://github.com/OCToNe1001/pantheon-releases/releases/download/v0.5.0-beta.10/PANTHEON-Windows-v0.5.0-beta.10.zip)**

1. ZIPをダウンロードして、すべて展開します。
2. 展開したフォルダーの **PANTHEON.exe** を開きます。
3. オンライン対戦は「スタート → オンライン対戦」から選びます。

Windows 10 / 11（64ビット）、Microsoft Edge WebView2 Runtime が必要です。初期キャラはミカエル・スサノオ・アヌビス。ゲーム内の神貨で全24キャラを解放できます。

## 遊べるモード

- 1人用：難易度を選べるCPU8連戦
- 2人用：同じPCで対戦
- オンライン：ランダムマッチ／招待コードで友達と対戦
- トレーニング／チュートリアル

ランダムマッチ成立時には、両者のキャラクターとプレイヤー名をVSカットインで表示して自動で対戦が始まります。再戦では同じ部屋でキャラクターを変更し、双方の準備完了で開始します。

## beta.10 の更新

オンライン対戦がマッチ成立後に開始しない問題を修正し、名前の禁止語・ローマ字チェックを強化しました。初回プロフィール、名前変更の1,000神貨・72時間制限、メールのNEW通知、スマホの表示改善も含みます。

- フレンド対戦・ランダムマッチ・再戦の開始判定を修正。
- 日本語・英語・ローマ字・混在表記を照合し、オンライン側でも名前を確認。
- 初回の名前設定は無料。変更は1,000神貨、設定・変更後72時間は変更不可。
- メールボックスにNEWと件数を表示。デイリー報酬はメールからも受取可能。
- Web版の再アクセス不具合を修正。開けない場合は[起動の修復](https://neon-break-arena-nov25.shiho-022685.chatgpt.site/repair)をご利用ください。
- スマホのステージ欄・ローカル2人対戦を非表示にし、戦闘中のページ移動・拡大を抑制。
- Webの設定 → 画面にスクショ互換モードを追加（実機の撮影結果は確認中）。
- セーブを保持し、WindowsとWebの引き継ぎにも対応。beta.8以降と対戦可能。

[詳しい更新内容](https://github.com/OCToNe1001/pantheon-releases/releases/tag/v0.5.0-beta.10)

## beta.2 の追加機能

- プロフィール：名前と全24人から選べるアイコン。名前はゲーム側とサーバー側でチェックします。
- キャラ資料：未解放キャラも、戦い方と実際の攻撃モーションを確認できます。
- 神との交流：神貨で贈り物を購入して好感度を10段階まで育成。全24人に各10章、計240章の個別ストーリーがあります。解放済みの章は何度でも読み返せます。
- 建御雷神などの武器モーションと、各神の命中エフェクトを強化しました。

## アップデート

**beta.5以降は起動時に更新を確認し、新版を自動ダウンロード・適用します。** 通信できないときは現在の版で起動できます。beta.4以前からの初回更新は **設定 → アップデート → アップデートを確認** で取得し、「ゲームを終了して更新」を選んでください。

アップデート機能のない旧版からは、ゲームを終了し、新しいZIPの中身をフォルダーごと上書きしてください。セーブデータ（神貨・解放キャラ・設定・プロフィール・好感度）は `%LOCALAPPDATA%\PANTHEON` に保存され、引き継がれます。
